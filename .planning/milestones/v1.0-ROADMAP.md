## Lessons / Notes

- **Milestone 範圍演進**：v1.0 從「process validation」擴張為「process validation + backend foundation」，藉 Phase 02-07 把所有橫切基建一次落地
- **D-08 4-step status-as-commit chain** 在每個 spec 都被嚴格執行（draft → approved → implementing → implemented 各自獨立 commit）
- **Pre-commit governance** 全程 110 commits hook-clean，零 `--no-verify`
- **PHASE-SUMMARY / plan SUMMARY 為 disk-only artifact**（per `.gitignore` SDD purist policy）— 對外契約由 specs + ADR + commit history 承擔
- **Docker-skip safety pattern**：MsSqlContainerFixture lazy build + IsContainerAvailable check，避免 Docker 不在時 fixture init NPE
- **xUnit v2 跨 asm collection**：consuming test asm 必須 re-declare `[CollectionDefinition]` stub（framework 限制）
