## Out of Scope (v1.0)

留給 v1.1+：

| Feature | Reason |
|---------|--------|
| 後端業務 API（任何 .NET 業務 endpoint） | v1.0 只做共用基建，business logic 留 v1.1+ |
| 真實 auth（JWT / session / user store / RBAC） | D14 推到 v1.1+；v1.0 只做 test-mode auth (D-19) 讓 [Authorize] 可測 |
| Auth state 模擬（router guard / localStorage `fakeLoggedIn`） | demo 雜訊 |
| Form validation（必填 / email 格式） | 純 UI 跳轉，欄位內容無意義 |
| 視覺設計系統 / design tokens | 用 Vue/CSS 預設，不抽元件 |
| 跨 browser / 響應式 / a11y 嚴格驗證 | dogfood 不做，未來 phase 再補 |
| 部署（Docker compose / Jenkins build） | 本機跑得起來即可 |
| Fugo / AD / Qdrant / 上線級監控 | v1.1+ |
