# Interviews

訪談紀錄。

## 檔名格式

`YYYY-MM-DD-<stakeholder>-<topic>.md`

範例：
- `2026-04-15-md-team-mdpicks.md`
- `2026-04-22-marketing-team-link.md`

## 紀律（沿用既有 SDD）

- **訪談完當天必建檔**
- **結論區 append-only**：不改寫，新內容加新段落（標日期）
- **My Take 區可改寫**：改寫加 `> [!tip] 框架升級 (date)`
- **訪談 unblock 對應 spec** → 在 spec 標 status 從 `blocked` → `draft`，並在 spec frontmatter 加 `related-interview`
